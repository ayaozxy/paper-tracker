### HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding
- **作者**: Chao Fang, Jun Yin, Man Shi, Marian Verhelst
- **来源**: arXiv:cs.AR  · `2607.22389v1`
- **链接**: https://arxiv.org/abs/2607.22389v1
- **PDF**: https://arxiv.org/pdf/2607.22389v1
- **发布日期**: 2026-07-24

> **动机**: 长上下文大语言模型在解码阶段的 KV cache 会持续增长，成为主要的内存瓶颈。作者希望利用 KV cache 的冗余，在尽量不损失精度的前提下提升解码效率。
> **方法**: HiKV 采用算法-硬件协同设计，将 KV cache 压缩分为两级：Stage I 在固定预算内淘汰不重要的 token，Stage II 只加载保留 token 中更重要的元素。硬件上实现了一个可重构的重要性排序器，能够在两种阶段所需的不同排序数据通路之间切换，以较小开销统一完成两级加速。
> **关键结果**: 在代表性 LLM 上，HiKV 相比传统 KV cache 基线在 attention 计算中最高可获得 7.95 倍加速和 90% 能耗降低，同时仅带来约 1% 的精度损失。与现有基于重要性的方法相比，在相同精度约束下还可额外减少 1.82 到 4.87 倍的外部内存访问。
> **与本课题相关性**: 该工作直接针对 LLM 解码中的 KV cache 存储与访问开销问题，属于长上下文推理加速与内存优化方向。它展示了通过重要性感知压缩与专用硬件协同设计来缓解 KV cache 瓶颈的有效思路。
> **局限**: 摘要中报告的收益是在“代表性 LLM”上评估得到，具体泛化到更多模型和场景的情况未在摘要中说明。方法仍依赖专用硬件，且存在约 1% 的精度损失与 8% 的系统面积增加。

### Unified Static-Dynamic Pruning for Efficient LLM Inference
- **作者**: Jinhyeok Kim, Yejoon Lee, Jaeyoung Do
- **来源**: arXiv:cs.DC  · `2607.21985v1`
- **链接**: https://arxiv.org/abs/2607.21985v1
- **PDF**: https://arxiv.org/pdf/2607.21985v1
- **发布日期**: 2026-07-24

> **动机**: 大语言模型在自回归解码阶段计算强度低、带宽受限，导致推理的计算和内存开销很高。现有剪枝方法要么是静态剪枝，缺乏对输入的自适应性，要么是动态剪枝，带来运行时不规则性。
> **方法**: 本文提出 SPDP，一个将非结构化静态剪枝与输入自适应动态剪枝统一起来的稀疏推理框架。它结合了新的 Tiled-Column-wise Bitmap Compressed（Tiled-CBC）格式，以及两个 GPU 内核：用于解码阶段的 CUDA-core spMspV 内核和用于 prefill 阶段的 Tensor-Core SpMM 内核。
> **关键结果**: 在面向推理优化的 GPU 上，SPDP 相比 SpInfer 等现有稀疏框架平均提速 1.24x–1.37x，最高可达 2.51x。它还能在最多高出 25% 稀疏度的情况下保持与基线相当的困惑度，并提升效率-质量折中表现。
> **与本课题相关性**: 这篇论文直接研究了大语言模型推理中的高效剪枝与稀疏计算，属于静态剪枝、动态剪枝和统一稀疏推理的典型工作。它展示了如何通过格式与内核协同设计，将静态与动态稀疏统一用于 LLM 推理加速。
> **局限**: 摘要没有明确列出方法的局限性。可以看出其设计依赖特定的 GPU 内核与稀疏格式，因此实际收益可能受硬件平台和实现复杂度影响。

### WaveformQA: Benchmarking LLM Temporal Reasoning on Digital Waveforms
- **作者**: Yichuan Liu, Daniel Cummings, Nick Vadlamudi
- **来源**: arXiv:cs.AI  · `2607.20638v1`
- **链接**: https://arxiv.org/abs/2607.20638v1
- **PDF**: https://arxiv.org/pdf/2607.20638v1
- **发布日期**: 2026-07-22

> **动机**: 作者指出，LLM 虽然在代码生成和推理上表现不错，但对数字波形进行时间序列推理的能力仍缺乏系统评估，而这正是设计验证中的关键瓶颈。现有基准多关注 HDL 代码生成，波形通常只作为辅助上下文，而非主要推理对象。
> **方法**: 论文提出了 WaveformQA，一个用于评估 LLM 数字波形时序推理能力的开源问答基准。该基准包含 360 个问题，覆盖 8 类不同难度，并使用程序生成的真值；波形来自开源设计实现，以保证可复现性和真实硬件语义。
> **关键结果**: 实验显示，前沿 LLM 在简单查询上还能达到较合理的准确率，但在复杂的时序和多步推理问题上表现明显下降，主要受上下文窗口限制和推理困难影响。作者还发现，相比标准 VCD 格式，事件时间 JSON 表示能提升 LLM 的推理准确率。
> **与本课题相关性**: 这项工作直接聚焦于“LLM 对数字波形的时间推理”这一主题，提供了一个专门的评测基准和可扩展框架。它有助于研究者系统分析模型在硬件验证场景中的时序理解能力。
> **局限**: 摘要表明当前模型在复杂多信号相关和事件排序等任务上仍存在明显不足，说明该方向仍有较大提升空间。另一个隐含限制是性能受上下文窗口长度影响较大，复杂问题更容易超出模型处理能力。

### AlphaRoute: Large Language Models as Semantic Optimizers for Multi-Objective Routing
- **作者**: Kabir Murjani, Mishri Bhavsar, Manish I. Patel, Jonti Talukdar
- **来源**: arXiv:cs.LG  · `2607.19768v1`
- **链接**: https://arxiv.org/abs/2607.19768v1
- **PDF**: https://arxiv.org/pdf/2607.19768v1
- **发布日期**: 2026-07-22

> **动机**: VLSI 全局路由是一个 NP-hard 的组合优化问题，需要在容量受限的 3D 网格中分配信号线网，并同时最小化拥塞、线长和过孔次数。传统启发式方法依赖静态惩罚调度，在复杂拥塞拓扑下效果不足，因此需要一种更自适应的优化框架。
> **方法**: AlphaRoute 将 rip-up and reroute（R&R）重构为动态多目标优化系统，并使用基于 SHAP 的 overflow 分解来定位每条 net 的拥塞来源，再通过 3D Dijkstra maze routing 和自适应 PathFinder 策略提取目标子图。其核心创新是把 LLM 作为语义策略优化器，在受确定性知识图约束下，根据拥塞指标动态调整惩罚参数。
> **关键结果**: 在 ISPD 2025 基准上，AlphaRoute 在 MEMPOOL 上将 overflow 降低了 98.6%。在受限的 ARIANE 设计上，overflow 达到 146,109，较当前最优方法降低 29.8 倍，惩罚分数从 SOTA 的 1.780 降至 0.0538。
> **与本课题相关性**: 这篇工作直接关注大语言模型在多目标路由优化中的作用，展示了 LLM 不仅能用于文本任务，也可作为语义策略模块参与复杂工程优化。它与“将 LLM 作为优化器或决策控制器”的研究主题高度相关。
> **局限**: 摘要强调结果来自特定基准测试，尚无法仅据此判断方法在更广泛设计上的泛化能力。摘要还提到 Python 实现存在延迟，说明方法的实际效率可能受实现方式影响。

### From Bit-Position Sensitivity to Unequal Error Protection for DNN Inference Memory
- **作者**: Muhammad Husnain Mubarik, Karthik Mohan Kumar, Pedro Antonio Pena, Keshavan Varadarajan, Kunal Tyagi
- **来源**: arXiv:cs.AR  · `2607.19623v1`
- **链接**: https://arxiv.org/abs/2607.19623v1
- **PDF**: https://arxiv.org/pdf/2607.19623v1
- **发布日期**: 2026-07-21

> **动机**: 作者希望了解DNN推理存储中不同比特位置的故障敏感性，并据此判断统一的SECDED保护是否过于保守。核心动机是利用“重要位更强保护、低重要位更弱保护”的思路来降低ECC存储开销。
> **方法**: 论文对16个推理工作负载进行了按比特位置的故障注入分析，覆盖基于Transformer的模型和无注意力CNN，并比较了三种浮点格式。基于实验中观察到的敏感性阈值Xsafe，作者进一步设计了带有按数据类型标签和双分区SRAM架构的Unequal Error Protection（UEP）编码器。
> **关键结果**: 实验发现低位尾数比特在特定阈值Xsafe以下翻转时，对任务指标的影响小于1%，而接近指数-尾数边界的位翻转会导致灾难性退化。作者给出了FP16、BF16和FP32的保守Xsafe下限，并声称可在无需重训练的情况下将ECC节省提升到37.5%–62.5%，同时相较统一SECDED将ECC面积降低27.8%。
> **与本课题相关性**: 这项工作直接关联“DNN推理存储中的位敏感性与差错保护”主题，展示了如何从比特级敏感性分析出发设计更高效的冗余保护机制。它也表明不同模型类别对保护强度的需求不同，因此UEP比统一保护更适合ML加速器场景。
> **局限**: 摘要主要报告了基于确定性单比特故障测试和870多次注入实验的结果，结论是否对更广泛的真实错误分布同样成立，摘要未明确说明。虽然作者提到对2-3位连续扰动也有效，但整体仍以特定工作负载、特定浮点格式和特定硬件架构为前提。

### BaseRT: Advancing Best-in-Class LLM Inference with Apple M5 Neural Accelerators
- **作者**: Fabian Waschkowski, Prabod Rathnayaka, Lukas Wesemann
- **来源**: arXiv:cs.AR  · `2607.19438v1`
- **链接**: https://arxiv.org/abs/2607.19438v1
- **PDF**: https://arxiv.org/pdf/2607.19438v1
- **发布日期**: 2026-07-21

> **动机**: 作者希望提升 Apple Silicon 上的大语言模型推理性能，特别是利用 M5 新增的 Neural Accelerator 来突破现有推理框架的吞吐上限。论文关注的是在设备端同时改善 prompt processing 和 decode 阶段的效率。
> **方法**: 作者在 BaseRT 这一原生 Metal 推理运行时中加入了一组手写的 Metal 4 tensor-core 内核，包括 dense 与 mixture-of-experts GEMM 以及 flash-attention prefill 内核。其策略是将计算密集型矩阵乘法转移到 M5 Neural Accelerators，而把内存带宽受限的 decode 路径保留在已有的专用内核上。
> **关键结果**: 在 Apple M5 Pro 上，BaseRT 在十五种模型配置上实现了相对 llama.cpp 最高 6.4× 的 prompt-processing 吞吐提升、相对 MLX 最高 3.9× 的提升，且在 decode 上仍保持领先，分别最高达 1.75× 和 1.33×。提升在 mixture-of-experts 模型上最明显，表明 M5 的 tensor cores 对 prompt processing 尤其关键。
> **与本课题相关性**: 这篇论文直接相关于端侧/本地 LLM 推理优化与硬件加速，展示了如何针对 Apple M5 的新型神经加速单元设计推理运行时。它为 Apple Silicon 上的高性能 LLM 部署提供了新的系统级实现路径。
> **局限**: 摘要主要报告了在 Apple M5 Pro 和特定模型家族上的实验结果，未提供跨硬件平台或更广泛场景下的验证。文中强调的是 prompt-processing 的显著收益，而 decode 阶段的提升相对有限，说明加速收益并非在所有推理环节都同样明显。

### BRIM: Workload-Balanced Dual-Sided Bit-Serial Sparse Inference Accelerator
- **作者**: Varun Manjunath, Ruokai Yin, Donghyun Lee, Arkapravo Ghosh, Priyadarshini Panda
- **来源**: arXiv:cs.AR  · `2607.19431v1`
- **链接**: https://arxiv.org/abs/2607.19431v1
- **PDF**: https://arxiv.org/pdf/2607.19431v1
- **发布日期**: 2026-07-20

> **动机**: 现有位串行加速器虽然能利用位级稀疏性降低DNN推理开销，但多数设计只利用单个操作数的稀疏性，速度提升受限。若同时利用权重和激活两侧的稀疏性，虽然能进一步减少部分积，但会引入严重的工作负载不均衡，导致PE利用率下降。
> **方法**: BRIM是一个软硬件协同设计的双侧位串行稀疏加速器，包含两项机制：离线的 Cyclic-Balanced Pruning（CBP）利用激活统计信息重塑权重表示，以平衡并行处理对的期望工作量；以及轻量级硬件机制 Pairwise Slot Donation，用于在运行时吸收剩余的不均衡。两者共同缓解双侧稀疏执行中的负载失衡问题。
> **关键结果**: 在CNN、ViT和LLM上、并在相同面积约束下评估时，BRIM将PE利用率提升到90%以上。相较于先前的双侧设计，它最高实现了2.37倍加速和1.63倍能效提升。
> **与本课题相关性**: 该工作直接面向DNN推理中的稀疏性利用与硬件加速，尤其关注位串行和双侧稀疏执行。它提出的方法针对稀疏加速器中“利用稀疏性但受负载不均衡限制”的核心瓶颈，具有明确的体系结构与算法结合意义。
> **局限**: 摘要主要报告了在CNN、ViT和LLM上的结果，以及在iso-area约束下的评估，因此结论主要基于这些设置。本文重点解决的是双侧位串行稀疏加速中的工作负载不均衡问题，对其他类型加速器或不同约束条件下的表现未在摘要中说明。

### SEAM-V: A Hybrid-Decoupled RISC-V Vector Processor with Backend-Visible EP Context for Sustained Vector Throughput
- **作者**: Weiying Wang, Zhiwei Zhang
- **来源**: arXiv:cs.AR  · `2607.17899v1`
- **链接**: https://arxiv.org/abs/2607.17899v1
- **PDF**: https://arxiv.org/pdf/2607.17899v1
- **发布日期**: 2026-07-20

> **动机**: 数据并行工作负载在深度学习和科学计算中持续推动对更高处理器吞吐、能效和可扩展性的需求。现有许多紧耦合的 RISC-V Vector 实现仍依赖标量核逐条供给向量指令，容易受到指令供给间隙、标量推进延迟以及保守依赖处理的影响。
> **方法**: SEAM-V 提出一种面向 RVV 的混合解耦向量执行架构，通过任务级解耦、本地指令供给和 VLIW 式打包形成连续的执行包（EP）流。EP 被序列化为请求后，其 EP 标识和请求绑定的预取上下文仍对动态向量后端可见，从而支持同 EP 候选相关 hazard 抑制、请求绑定预取，并在满足安全条件时提供有限的跨 EP 向量重叠。
> **关键结果**: 周期精确 RTL 评估显示，相比基于 Ara 的紧耦合 RVV 实现，SEAM-V 在 17 个代表性内核上获得 1.34x 的几何平均加速。三类应用组分别达到 1.50x、1.25x 和 1.27x，加上在 AVL=32 时六个一维向量内核的几何平均加速接近 3x。
> **与本课题相关性**: 这项工作直接讨论了 RISC-V 向量处理器的体系结构优化，重点在于通过解耦与后端可见上下文来提升持续向量吞吐。它对研究 RVV 的执行效率、依赖处理和预取机制具有较强相关性。
> **局限**: 该摘要主要报告了与单一紧耦合基线（Ara-based TC）的对比结果，未给出更广泛的硬件平台或工作负载覆盖情况。摘要也未展开说明面积、功耗、实现复杂度以及在更多安全条件下跨 EP 重叠的边界。

### New Number Formats for FFT IP Cores in Optical OFDM Transceivers
- **作者**: Lukas Krupp, Gustavo Magalhães Gomes De Souza, Sani Nassif, Norbert Wehn
- **来源**: arXiv:cs.AR  · `2607.17835v1`
- **链接**: https://arxiv.org/abs/2607.17835v1
- **PDF**: https://arxiv.org/pdf/2607.17835v1
- **发布日期**: 2026-07-20

> **动机**: 传统DSP实现通常采用定点运算以降低硬件复杂度并提高吞吐量，但机器学习加速器中低精度浮点格式的进展引发了对经典DSP工作负载数值表示的重新思考。作者希望评估低精度浮点是否能在保持更大动态范围和数值鲁棒性的同时，达到与定点实现相当的功耗、性能和面积。
> **方法**: 论文提出了一种跨层协同设计方法，联合优化数值表示、算术单元和应用层性能，并以FFT为案例研究。作者在12nm FinFET工艺下，对光OFDM收发器中的FFT核心进行后布局功耗和面积评估，并用BER对Eb/N0的系统级指标比较定点与低精度浮点格式。
> **关键结果**: 对于128 Gbit/s收发器中的256点FFT引擎，11位和12位自定义浮点格式在多个调制阶数下的BER表现接近32位浮点参考。相比代表性的定点设计，FFT核心功耗最高降低19.8%，面积最高降低12.0%。
> **与本课题相关性**: 这项工作直接讨论了FFT IP核的新数值格式，尤其是面向光OFDM收发器的低精度浮点方案。它表明自定义浮点格式可能成为高吞吐DSP硬件中定点之外的可行选择。
> **局限**: 结果基于特定案例：12nm工艺、256点FFT以及128 Gbit/s光OFDM收发器，因此泛化到其他工艺、FFT规模或系统配置仍需进一步验证。摘要还未说明这些自定义格式在更广泛DSP场景中的适用性或设计复杂度代价。

### D-NOVA: In-Storage Retrieval Accelerator via Dual-Bound 3D NAND-Optimized Similarity Search with Vector Adaptation
- **作者**: Chang Eun Song, Sumukh Pinge, Tianqi Zhang, Sung Eun Kim, Tajana S. Rosing et al.
- **来源**: arXiv:cs.AR  · `2607.17538v1`
- **链接**: https://arxiv.org/abs/2607.17538v1
- **PDF**: https://arxiv.org/pdf/2607.17538v1
- **发布日期**: 2026-07-20

> **动机**: RAG 的稠密向量检索会带来显著的延迟和能耗开销，已成为整体性能瓶颈。现有的 in-storage 加速器虽然减少了部分数据搬移，但仍依赖存储器外的主机或嵌入式处理器，无法彻底消除带宽限制。
> **方法**: D-NOVA 是一种软硬件协同设计的 in-storage 检索加速器，将基于 IVF 的分层检索流程深度嵌入 NAND 存储阵列中。它引入了面向 NAND 字符串搜索的 Dual-Bound Tight Similarity Sensing（DTS）距离度量，并配合一个轻量级对比学习适配器，把向量映射到更适合 DTS 的空间。
> **关键结果**: 实验结果显示，D-NOVA 相比 CPU 基线最高可快 41.7 倍、节能 71 倍。与最先进的 in-storage RAG 加速器相比，它的吞吐量最高提升 12.13 倍，同时能效最高提升 1.26 倍，并且召回率接近软件实现。
> **与本课题相关性**: 该工作直接面向大模型 RAG 场景中的向量检索加速问题，核心贡献是把检索逻辑尽可能前移到存储内部。它展示了完全 in-storage 的向量搜索在可扩展 RAG 加速中的潜力。
> **局限**: 摘要表明该方案依赖特定的 3D NAND 阵列结构以及专门设计的 DTS 度量和向量适配器，因此可移植性可能受硬件约束。文中未在摘要中给出对不同数据集、不同模型或更广泛系统环境下表现的详细讨论。

### Can AI Agents Really Complete RTL-to-GDS? Lessons from Benchmarking Tool-Interactive EDA Workflows
- **作者**: Jinyuan Deng, Zhengrui Chen, Xufeng Wei, Tianyu Xing, Chenyi Wen et al.
- **来源**: arXiv:cs.AI  · `2607.17528v3`
- **链接**: https://arxiv.org/abs/2607.17528v3
- **PDF**: https://arxiv.org/pdf/2607.17528v3
- **发布日期**: 2026-07-20

> **动机**: 作者想弄清楚，具备 EDA 领域技能的通用编码型 LLM 代理，是否真的能够可靠完成从 RTL 到 GDS 的长链路工具交互流程。尤其关注综合、物理实现和 ECO 优化等环节中，现有 agent 的实际可行性与稳定性。
> **方法**: 他们在 PicoRV32 的 RTL-to-GDS 流程上，使用商业 EDA 工具，在两种时序目标下评测 AI 代理。评估指标包括端到端设计得分、阶段完成情况，以及衡量设计质量与运行成本关系的 Token ROI，并比较了三种 agent 架构和四种基础模型。
> **关键结果**: 研究总结出三点：第一，领域技能能提升代理对单个子任务的理解，但不能保证长流程可靠完成；第二，设计进展相近的代理在 Token ROI 上最多可相差 141 倍，说明效率差异极大；第三，低层工具接口不匹配是物理设计失败的重要来源，尤其是 Tcl 命令依赖工具版本或执行模式时。
> **与本课题相关性**: 这篇工作直接讨论了 AI agent 是否能够完成 RTL-to-GDS 这样的长时程 EDA 工作流，因此与“Agentic EDA”和工具交互式自动化高度相关。它为评估 AI 在芯片设计自动化中的能力边界提供了实证依据。
> **局限**: 摘要显示实验只基于 PicoRV32 这一条设计流程，并在两种时序目标下进行测试，因此结果的泛化范围有限。研究主要聚焦商业工具环境下的 benchmark，未说明是否覆盖更广泛的设计规模、更多芯片项目或不同 EDA 工具链。

### Chip Floorplanning Combining Convex and Non-convex Optimization
- **作者**: Yilihamujiang Yimamu, Guillem Pastor-Rué, Jordi Cortadella
- **来源**: arXiv:cs.AR  · `2607.21408v1`
- **链接**: https://arxiv.org/abs/2607.21408v1
- **PDF**: https://arxiv.org/pdf/2607.21408v1
- **发布日期**: 2026-07-23

> **动机**: 芯片floorplanning是VLSI物理设计中的关键早期步骤，其质量会直接影响互连线长、芯片性能以及后续设计效率。该工作旨在提升固定外框约束下的floorplanning质量，尤其关注线长和重叠问题的联合优化。
> **方法**: 作者提出了一个三阶段框架，结合非凸与凸优化：先用二次布局生成具有拓扑感知的初始方案，再用基于Adam的投影梯度方法进行全局floorplanning以减少线长和重叠，最后用基于水平/垂直约束图的对数变换凸模型消除残余重叠。
> **关键结果**: 在MCNC、GSRC和HB+基准上，该框架取得了状态最优级别的线长表现。与测试基准上的现有floorplanner相比，平均HPWL至少降低了1%和5%。
> **与本课题相关性**: 这篇论文直接讨论芯片floorplanning问题，并提出了一个将凸优化与非凸优化结合的求解框架。它与芯片物理设计中的布局优化、线长最小化和重叠消除高度相关。
> **局限**: 摘要未报告运行时间、可扩展性细节或对更大规模工业设计的验证结果，因此这些方面的局限无法从摘要中确定。摘要也没有展开说明在不同约束条件下方法稳定性或参数敏感性。

### High-Level Synthesis of Efficient Pipelines with Visibility Control
- **作者**: Jungin Rhee, Minseong Jang, Jaewoo Kim, Jeehoon Kang
- **来源**: arXiv:cs.PL  · `2607.18765v1`
- **链接**: https://arxiv.org/abs/2607.18765v1
- **PDF**: https://arxiv.org/pdf/2607.18765v1
- **发布日期**: 2026-07-21

> **动机**: 高层次综合（HLS）希望将硬件设计从并发的RTL提升到顺序程序层面，但流水线设计仍需要对结构和冒险处理进行细粒度控制，才能获得有竞争力的功耗、性能和面积（PPA）。现有工具要么缺乏这种控制，要么为了提供控制而牺牲了顺序语义。
> **方法**: 作者提出了一种HLS工具，将细粒度的流水线控制嵌入顺序编程模型中，以支持快速的设计空间探索。该工具基于一种名为visibility control的新编程抽象，统一了停顿、旁路、推测、延迟提交和寄存器重命名等冒险处理策略。
> **关键结果**: 在RISC-V核心、直方图和AES加速器等案例上进行了评估：RISC-V核心中实现了停顿、旁路、推测和寄存器重命名，直方图中实现了原本需要RTL或并发编程模型的调度策略。综合结果显示，编译得到的流水线优于支持顺序语义的HLS工具，并且PPA可与手写RTL相当。
> **与本课题相关性**: 这篇论文直接讨论了HLS中流水线化与冒险控制的实现方式，属于高层次综合与硬件流水线优化的核心主题。它展示了如何在保持顺序语义的同时提供接近RTL级别的控制能力，对流水线设计研究具有较强相关性。
> **局限**: 摘要没有给出该方法在更广泛应用中的局限性、开销或适用范围，因此难以判断其通用性与实现复杂度。文中只说明在若干案例上表现良好，但未提供更细的定量比较细节。

### A Progressive Approach to Synthesizable RTL Design Generation Using LLMs
- **作者**: Xiangfei Kong, Tasnim Tabassum, Marwan Abdelwahab, Hao Zheng
- **来源**: arXiv:cs.AR  · `2607.18519v1`
- **链接**: https://arxiv.org/abs/2607.18519v1
- **PDF**: https://arxiv.org/pdf/2607.18519v1
- **发布日期**: 2026-07-20

> **动机**: LLM可以从自然语言直接生成RTL，但其主要失败往往来自对规格的误解而非代码编写本身。由于规格本身含糊且模型的理解隐式化，误读会被直接写入Verilog，往往只能在仿真阶段才被发现。
> **方法**: 论文提出 VeriRefine，将规格细化作为RTL生成中的可验证阶段：先把自然语言逐步细化为带schema约束的设计意图表示，并用每个信号的ASTF显式固定逻辑风格、时钟域和复位行为。随后通过五层审计检查健全性、完整性、一致性、FSM完整性和核心RTL规则，并将仿真失败区分为理解错误或编码错误，回流到对应阶段修复。
> **关键结果**: 在 Claude Sonnet 4.6 下，VeriRefine 在 RTLLM v2.0 上达到 94.0% 的功能正确率，在 VerilogEval-Human v2 上达到 98.1%。摘要还指出，由于每个信号的硬件类别在细化阶段已固定，可综合性成为流水线的结构性质。
> **与本课题相关性**: 这篇工作直接针对“用LLM生成可综合RTL”的问题，重点不只是生成代码，而是先把规格理解显式化并可验证。它强调通过逐层细化和审计来提升生成RTL的正确性与可综合性。
> **局限**: 摘要没有明确列出局限性；从描述看，该方法仍依赖仿真来发现代码层面的失败，并依赖LLM进行规格细化与代码生成。其效果也仅在给定基准和所用模型上报告，尚不能从摘要中判断泛化边界。

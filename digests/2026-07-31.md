### ARES: Adaptive Reasoning-Effort Steering for PPA- and Cost-Aware RTL Optimization with LLM Agents
- **作者**: Stef Cuyckens, Mihaela Jivanescu, Jun Yin, Chao Fang, Marian Verhelst
- **来源**: arXiv:cs.AR  · `2607.27879v1`
- **链接**: https://arxiv.org/abs/2607.27879v1
- **PDF**: https://arxiv.org/pdf/2607.27879v1
- **发布日期**: 2026-07-30

> **动机**: 现有用于 RTL 优化的 LLM agents 会在反复编辑、综合与 PPA 分析中消耗大量调用成本，但以往工作通常只报告最终质量，而没有按统一方式衡量每次调用的美元成本。作者希望在考虑成本的前提下，更公平地比较不同推理策略，并提高优化效率。
> **方法**: 提出 ARES，一方面为每次 LLM 调用引入归一化美元成本，并将其与 FoM 一起报告；另一方面通过 21 个训练设计拟合一个“耐心计数器”策略，在低推理开销下停滞时才升级到更深层推理，从而按需分配 reasoning effort。与此同时，作者发现长期记忆的具体构造并不关键，简单拼接历史经验与工程化记忆相比没有稳定优势。
> **关键结果**: 在 3 个未见过的测试设计上，该推理策略在相同归一化成本下将 FoM 降低 23%-27%，优于最佳固定推理开销设置的 16%-23%。此外，ARES 最多可弥合从 LLM 生成的乘加器到高度人工优化版本 83% 的差距，并以仅 12% 的 tokens 达到比 SOTA Dr. RTL 深 25% 的 FoM。
> **与本课题相关性**: 这项工作直接面向基于 LLM agent 的 RTL 设计优化，关注 PPA、成本与推理策略的联合权衡。它说明在硬件设计自动优化中，动态调整 LLM 推理强度可能比固定策略更有效。
> **局限**: 摘要显示该方法的推理策略是在 21 个训练设计上拟合得到，测试只在 3 个未见设计上验证，因此泛化范围仍有限。摘要也表明工程化长期记忆没有稳定收益，但并未说明在更大规模或不同 RTL 场景下是否仍然如此。

### LightRot: A Light-Weighted Rotation Scheme and Architecture for Accurate Low-Bit Large Language Model Inference
- **作者**: Sangjin Kim, Yuseon Choi, Jungjun Oh, Byeongcheol Kim, Hoi-Jun Yoo
- **来源**: arXiv:cs.AR  · `2607.27704v1`
- **链接**: https://arxiv.org/abs/2607.27704v1
- **PDF**: https://arxiv.org/pdf/2607.27704v1
- **发布日期**: 2026-07-30

> **动机**: 随着大语言模型能力持续提升，如何在保证准确性的同时实现更低能耗、更高效率的推理变得越来越重要。该工作旨在解决低比特量化推理中旋转操作带来的能量开销问题。
> **方法**: 作者提出了 LightRot，一种轻量级旋转方案及专用硬件加速器。其核心包括 Grouped Local Rotation（GLR）、Outlier Direction Aligning（ODA），以及基于分层 Fast Hadamard Transform（FHT）的旋转单元。
> **关键结果**: 该加速器在 28nm CMOS 工艺下实现了 4-bit 推理最高 27.4 TOPS/W 的能效，优于先前最先进设计。实验还在 LLaMA2-13B、LLaMA3-8B 和 MT-Bench 上验证了其适用于更真实的对话场景。
> **与本课题相关性**: 这篇论文直接聚焦于低比特大语言模型推理的算法与硬件协同优化，属于高效 LLM 推理与加速器设计主题。它展示了通过旋转方案与硬件架构联合设计来提升能效和实用性的路径。
> **局限**: 摘要中没有明确讨论方法的局限性或失败案例，因此无法从摘要中提取具体限制。仅能看出其评估重点主要放在低比特推理能效和若干大模型/对话基准上。

### GyRot: Leveraging Hidden Synergy between Rotation and Fine-grained Group Quantization for Low-bit LLM Inference
- **作者**: Sangjin Kim, Yuseon Choi, Byeongcheol Kim, Jungjun Oh, Hoi-jun Yoo
- **来源**: arXiv:cs.AR  · `2607.27694v1`
- **链接**: https://arxiv.org/abs/2607.27694v1
- **PDF**: https://arxiv.org/pdf/2607.27694v1
- **发布日期**: 2026-07-30

> **动机**: 低比特量化对大语言模型推理效率至关重要，旋转（rotation）和细粒度分组量化（fine-grained group quantization）各自都有效。摘要指出，两者直接结合时常会因旋转的全局性质与分组缩放的局部行为不匹配而带来精度下降或硬件开销。
> **方法**: 提出 GyRot，一个结合算法与硬件协同设计的量化框架和加速器。它通过 Coarse Rotation, Fine Grouping（CoRFiG）和 Harmonic-Aligned Permutation（HAP）来协调旋转与分组量化，并重新表述非对称量化、引入零点舍入策略以实现全整数反量化。
> **关键结果**: 在基于 INT4 的张量 PE 架构上，GyRot 在 LLaMA 系列模型上实现了最先进的 4-bit 精度。与此同时，相比基线 LLM 加速器，最高可获得 3.4 倍加速和 3.6 倍能效提升。
> **与本课题相关性**: 该工作直接面向低比特大语言模型推理中的量化问题，核心关注点是如何把旋转与分组量化有效结合。它同时覆盖量化算法设计与硬件实现，因此与高效 LLM 推理和低比特部署主题高度相关。
> **局限**: 摘要未明确给出局限性。根据摘要可知，该方法是在特定的 INT4 张量 PE 硬件架构上实现与评估的，因此其效果展示主要依赖于这种算法-硬件协同设置。

### NELSSA: A GPU-PNM Heterogeneous System for Mixed-Length LLM Serving via Length-based Request Placement
- **作者**: Sookyung Choi, Seungyong Lee, Kangkyu Park, Yunseo Chun, Junseok Lee et al.
- **来源**: arXiv:cs.AR  · `2607.26633v1`
- **链接**: https://arxiv.org/abs/2607.26633v1
- **PDF**: https://arxiv.org/pdf/2607.26633v1
- **发布日期**: 2026-07-29

> **动机**: 现代LLM及其智能体应用带来了从几百到几十万token不等的混合长度请求，并且这些请求会在同一服务窗口内交错出现。现有以GPU为中心的推理架构在这类负载下效率受限，尤其当批处理需要兼顾大上下文和内存约束时。
> **方法**: NELSSA将GPU与真实的近存计算（PNM）加速器结合，采用基于长度的请求放置策略：短上下文请求分配到GPU，长上下文请求分配到PNM。系统还支持运行时迁移，以便在上下文增长时无需重新计算即可跨层转移请求，并在CXL互联、RPC和RDMA支持下完成调度与内存移动。
> **关键结果**: 在混合长度LLM工作负载上，NELSSA相较GPU-only基线将解码吞吐提升最高达5.5倍，并将P99延迟降低最高达15倍。作者的端到端原型与实验表明，GPU-PNM一体化服务是一种有前景的LLM基础设施方案。
> **与本课题相关性**: 这篇论文直接关注LLM服务系统在混合长度请求下的调度与资源异构协同问题，属于LLM推理/Serving系统优化的核心主题。其方法体现了利用异构硬件和请求放置策略提升吞吐与延迟表现的系统设计思路。
> **局限**: 摘要中没有给出明确的局限性分析，因此无法从其内容中确认方法在不同模型、不同PNM硬件或更大规模部署下的边界条件。仅能看出其结果来自端到端原型与实验评估，具体泛化能力仍需结合全文进一步判断。

### LLMET: Enabling Cross-Layer Evaluation of Emerging M3D Memories for Energy-Efficient LLM Serving
- **作者**: Ming-Yen Lee, Hanchen Yang, Faaiq Waqar, Harsono Simka, Tushar Krishna et al.
- **来源**: arXiv:cs.AR  · `2607.26491v1`
- **链接**: https://arxiv.org/abs/2607.26491v1
- **PDF**: https://arxiv.org/pdf/2607.26491v1
- **发布日期**: 2026-07-29

> **动机**: LLM 服务的能耗正在成为系统级挑战，主要受芯片功耗、热约束和电费上升驱动。作者关注的核心问题是：随着新型存储技术把片上缓存继续做大，是否真的能有效提升 LLM serving 的能效。
> **方法**: 作者提出并验证了一个跨层仿真框架 LLMET（LLM with Emerging Technology），用于评估新兴 M3D 存储技术对 LLM 服务的影响。该框架覆盖多种模型、应用和平台，并分析了扩大 L2 cache 容量带来的能耗变化。
> **关键结果**: 在双 NVIDIA A100 GPU 平台上，将 L2 cache 从 40MB 扩大到 1GB，可使 Llama3.1-70B 在 16K 上下文 prefill 阶段的芯片能耗降低 44%。在 8x NVIDIA B200-like 平台上，将 L2 cache 从 128MB 扩大到 4GB，prefill 能耗最高可节省 24%；在边缘平台上，decode 能耗最高可降低 30%。
> **与本课题相关性**: 这篇论文直接讨论了新兴 M3D 3D 存储如何通过扩大片上缓存来减少对 HBM 的访问，从而支持更节能的 LLM serving。它为“面向高效 LLM 服务的存储/内存技术”提供了跨层评估证据。
> **局限**: 文中结果来自 LLMET 仿真框架和特定平台/工作负载设置，未在摘要中宣称已经在真实系统中全面部署验证。结论主要说明在所研究场景下超大容量片上缓存具有潜力，外推到其他模型或硬件仍需进一步验证。

### Beyond Prefill-Decode Disaggregation: Dissecting LLM Inference for Heterogeneous Platforms via Dynamic Operator Scheduling
- **作者**: Jiaqi Yang, Jiayi Li, Yihan Fu, Hongxiao Zhao, Zhan Chen et al.
- **来源**: arXiv:cs.AR  · `2607.25498v1`
- **链接**: https://arxiv.org/abs/2607.25498v1
- **PDF**: https://arxiv.org/pdf/2607.25498v1
- **发布日期**: 2026-07-28

> **动机**: 现有的prefill-decode disaggregation（PD）和基于roofline的算子放置方法，往往难以在实际异构平台上最小化LLM推理端到端延迟。作者指出，负载形状、运行时设备争用以及持续存在的权重布局都会显著影响性能，因此需要更细粒度、动态的调度方法。
> **方法**: 本文提出DOPS（dynamic operator scheduling），这是一个面向硬件的闭环框架，联合优化算子调度与块级权重布局。DOPS构建了一个stage-aware DAG，并包含Bifocal调度器用于动态分配算子到设备，以及Weight Layout Arbiter（WLA）在严格内存约束下选择更高效的权重布局。
> **关键结果**: 在由NPU和PIM组成的代表性异构系统上，Bifocal相较PD基线取得1.20×到2.23×的几何平均加速。WLA在Bifocal/Linear之上还能带来额外1.28×到1.33×的几何平均加速。
> **与本课题相关性**: 这篇工作直接讨论了LLM在异构平台上的推理分解与调度问题，属于“超越prefill-decode disaggregation”的系统优化研究。它强调算子级动态调度与权重布局协同优化，和异构LLM推理部署主题高度相关。
> **局限**: 摘要中未明确说明该方法的局限性或失败案例。仅能确定其性能评估覆盖了代表性异构系统，但无法从摘要判断其对更多硬件类型或更大规模模型的泛化边界。

### ContractHIL-HLS: Contract-Aligned Multi-Agent Workflow with Hardware-in-the-Loop Feedback for HLS Design
- **作者**: Jingbo Zhang, Haoxiang Sun, Wenbo Wang, Wenbo Zhang
- **来源**: arXiv:cs.AI  · `2607.25283v1`
- **链接**: https://arxiv.org/abs/2607.25283v1
- **PDF**: https://arxiv.org/pdf/2607.25283v1
- **发布日期**: 2026-07-28

> **动机**: 该工作旨在提升大语言模型辅助的高层次综合（HLS）工程能力，尤其解决自然语言需求到可执行设计之间的语义对齐，以及从核函数代码走向系统/板级闭环验证的问题。作者希望将硬件实测反馈纳入生成与修正过程，以提高设计落地性。
> **方法**: 提出 ContractHIL-HLS，一种契约对齐的多智能体工作流：用结构化 contract 将自然语言需求转换为接口、约束、验证检查和回滚规则，再将 HLS、Vivado、PYNQ 运行、功耗和失败证据反馈回生成环节。系统由 Contract Agent、HTML Agent 和 Hardware-in-the-Loop Agent 组成，分别负责语义下推、结构化展示和基于实测证据的实现/修订。
> **关键结果**: 在 94 个可本地执行的 HLS-Eval 任务上，结构化 contract 将单样本测试平台通过率从 64.0% 提升到 70.2%，完整流程达到 70.4% 的 pass@1 和 76.6% 的 pass@5。另在板级测试的 ML-KEM/ML-DSA PQC 加速器上，六消息平均文本运行时间从 207.3 ms 降至 52.4 ms，同时两种镜像均保持正的路由后 WNS 且解密消息校验通过。
> **与本课题相关性**: 这篇论文与“基于约束/契约的多智能体协作”和“硬件在环反馈驱动的自动化 HLS 设计”高度相关，展示了如何把自然语言需求、结构化约束与真实硬件证据结合起来。它对需要将 LLM 用于 FPGA/HLS 设计闭环优化的研究很有参考价值。
> **局限**: 摘要也指出，HLS-Eval 主要是核函数级任务，不能覆盖板级设计，因此作者额外用了一个板级 PQC 加速器案例进行验证。文中未在摘要中给出更广泛的硬件类型、任务规模覆盖或对其他 HLS 场景的泛化边界。

### Nanoparticle Networks for Neuromorphic Computing
- **作者**: Jonas Mensing, Wilfred G. van der Wiel, Andreas Heuer
- **来源**: arXiv:cs.ET  · `2607.27844v1`
- **链接**: https://arxiv.org/abs/2607.27844v1
- **PDF**: https://arxiv.org/pdf/2607.27844v1
- **发布日期**: 2026-07-30

> **动机**: 作者旨在利用复杂动态物理系统实现更节能的计算，探索一种基于金属纳米颗粒与分子结的神经形态架构。研究关注静态控制电极如何将原本被动的纳米颗粒网络转化为可调的非线性动力学系统。
> **方法**: 在SiO2/Si衬底上的金属纳米颗粒网络中引入周围静态控制电极，并分析一维电压输入如何被路由为多维信号响应。进一步通过调节工作频率、SiO2厚度以及分子结异质性来考察其计算性能与记忆特性。
> **关键结果**: 作者总结出三条提升计算性能的设计规则：在截止频率附近工作可平衡非线性隧穿与线性电容记忆；SiO2厚度决定屏蔽长度和记忆类型，厚氧化层会使大于屏蔽长度的网络进入更持久的非挥发式状态；引入结构无序可突破表达能力受屏蔽长度限制的饱和，从而提升动态神经形态应用中的性能。
> **与本课题相关性**: 这项工作直接相关于神经形态计算中的物理实现路径，展示了纳米颗粒网络如何通过外部电极调控获得可编程的动态响应。它为设计高表达力、具有不同记忆特性的物理计算硬件提供了具体原则。
> **局限**: 摘要指出网络的计算表达能力会随物理尺寸增长，但最终仍受屏蔽长度限制，因此并非无限增强。其性能提升还依赖特定材料结构与电极设计，结果主要围绕该纳米颗粒体系展开。

### At-the-Roofline Sparse Tensor Contractions on Vector Processors for Transformer Inference
- **作者**: Bowen Wang, Chi Zhang, Diyou Shen, Renzo Andri, Navaneeth Kunhi Purayil et al.
- **来源**: arXiv:cs.AR  · `2607.25504v1`
- **链接**: https://arxiv.org/abs/2607.25504v1
- **PDF**: https://arxiv.org/pdf/2607.25504v1
- **发布日期**: 2026-07-28

> **动机**: Transformer 推理中的细粒度权重剪枝和激活稀疏化可以降低计算与内存开销，但在中等稀疏度下，现有 RVV 架构对 Gustavson 数据流缺乏原生支持，导致稀疏张量收缩性能远低于理论上界。作者希望通过更贴近 roofline 的硬件支持来提升这类稀疏计算的效率。
> **方法**: 提出 Ventaglio：一种可运行时配置的稀疏执行单元，并配套 RVV ISA 扩展，提供 indexed gather-accumulate-scatter 支持以加速稀疏张量收缩。论文还实现了一个开源向量处理器集群中的原型，并建立了经过 RTL 校准的指令级性能模型用于大规模性能分析。
> **关键结果**: 在 12nm 工艺实现中，Ventaglio 相比优化过的 RVV 基线可将稀疏张量收缩核加速 6.9–7.4 倍，且对紧耦合 L1 的向量处理器集群仅带来 3.1% 的面积开销。对 DuoGPT-pruned 的 LLaMA-3-8B 模型，在 40%–60% 的双稀疏下，prefill 和自回归解码分别实现 2.40–5.25 倍和 2.06–3.16 倍的加速。
> **与本课题相关性**: 这篇工作直接讨论了 Transformer 推理中的稀疏张量收缩加速，是“面向 Transformer 推理的稀疏计算/硬件加速”主题下的典型研究。它聚焦于向量处理器上的稀疏执行支持，并展示了从 ISA 到硬件原型再到模型级加速的完整路径。
> **局限**: 摘要主要报告了中等稀疏度场景和特定模型上的结果，因此结论是否可推广到其他稀疏模式、模型规模或硬件平台仍需进一步验证。文中性能评估依赖于原型实现与建模分析，实际部署时的系统级开销也未在摘要中展开。

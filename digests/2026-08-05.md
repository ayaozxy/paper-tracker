### Heterogeneity-Aware Microscaling for Efficient Low-Bit LLM Inference
- **作者**: Junyi Luo, Xinting Jiang, Tai-Hao Wen, Ruichen Qi, Minxing Chu et al.
- **来源**: arXiv:cs.AR  · `2608.03867v1`
- **链接**: https://arxiv.org/abs/2608.03867v1
- **PDF**: https://arxiv.org/pdf/2608.03867v1
- **发布日期**: 2026-08-04

> **动机**: 现有 Microscaling（尤其是 MXFP4）在低比特 LLM 推理中仍会带来明显精度损失，因为它们通常在所有 block 上固定同一种元素格式或精度恢复方案，难以覆盖量化异质性。作者指出这种异质性既存在于不同 block 之间，也存在于权重与激活这两类操作数之间。
> **方法**: 提出 AdaMX（Adaptive Microscaling），在不增加等效比特宽度（EBW）的前提下，按 block 选择精度恢复方案，并按操作数选择表示方式。该方法还覆盖两种 block size，对应一个更高精度的配置和一个更低 EBW、节省存储的配置，并实现了 22nm FD-SOI AI 加速器原型。
> **关键结果**: 在与仅将乘法器设为 FP4 的 MXFP4 加速器相比时，AdaMX 仅增加约 1% 的系统能耗；在低 EBW 配置下，它在保持更高精度的同时还能降低内存占用和能耗。对 3B 到 70B 的 LLM，AdaMX 在常识任务上消除了 83% 的 MXFP4 精度损失，在 MMLU 上消除了 82%，相较 NVFP4 也分别消除了 43% 和 27% 的损失。它还能推广到多模态模型，在 Gemma-4 12B 上优于 MXFP4，并在四个视觉语言基准上最高达到 FP16 精度的 96%。
> **与本课题相关性**: 这篇论文直接讨论了低比特 LLM 推理中的微缩放量化与硬件加速，是“高效低比特推理”主题下的代表性工作。它的核心贡献在于用异质性感知的设计提升 4-bit 推理精度，同时尽量保持硬件开销很低。
> **局限**: 摘要主要报告了特定模型和基准上的结果，以及一个 22nm 原型的能耗开销；未提供更广泛的系统级部署细节或训练相关影响。文中结论也主要基于所测试的 LLM 和多模态模型，适用范围仍以这些实验设置为准。

### Heterogeneous LLM Serving with General-Purpose Processing-Near-Memory for Retrieval-Based Sparse Attention
- **作者**: Hyungkyu Ham, Junhyeong Bae, Seungheon Lee, Myeongjae Jeon, Gwangsun Kim
- **来源**: arXiv:cs.AR  · `2608.03555v1`
- **链接**: https://arxiv.org/abs/2608.03555v1
- **PDF**: https://arxiv.org/pdf/2608.03555v1
- **发布日期**: 2026-08-04

> **动机**: 为了支持百万级上下文的检索式稀疏注意力，作者关注在解码阶段将 KV cache 从 GPU 显存中移出，以降低 GPU 内存压力并提升推理服务能力。现有面向 PIM/PNM 的设计假设已不再适用于这类读写 KV cache 的操作，因此需要新的系统与硬件协同方案。
> **方法**: 论文提出一种异构解码阶段服务系统：GPU 负责模型权重、投影和 MoE 层，而处理近存储（PNM）节点保存 KV cache 和索引键，并执行所有读取这些数据的操作。基于新的设计需求，作者提出通用型 PNM 设计 KARAT，以及用于减少流水线空泡的 OFMS 和 CMR 调度策略。
> **关键结果**: 在三种先进模型和真实 agentic traces 上，该系统在满足服务级目标时，相比仅 GPU 基线可将单位 TDP 吞吐提升 2.09–6.13 倍。对于无需训练的稀疏注意力方法，也取得了 1.36–3.21 倍的提升。
> **与本课题相关性**: 这篇工作直接讨论了大语言模型服务、KV cache 管理、近存储计算以及检索式稀疏注意力，属于 LLM 高效推理/服务系统方向。它尤其关注在超长上下文场景下，如何通过异构硬件与调度优化提升吞吐与能效。
> **局限**: 摘要未给出该方法在更广泛模型、硬件平台或更复杂负载下的通用性边界，也没有详细说明代价和实现开销。其结论主要基于三种模型与真实轨迹实验，完整适用范围仍需查看正文验证。

### ComFuse: Fusing Complex Memory-Intensive Subgraphs with Compute-Intensive Kernels For Modern GPU Architectures
- **作者**: Di Mu, Tengyuan Jin, Zhenkun Wang, Jialin Yang, Yusen Li et al.
- **来源**: arXiv:cs.AR  · `2608.03537v1`
- **链接**: https://arxiv.org/abs/2608.03537v1
- **PDF**: https://arxiv.org/pdf/2608.03537v1
- **发布日期**: 2026-08-04

> **动机**: 现代深度学习工作负载越来越多地包含计算密集型算子与内存密集型子图的异构组合，但现有编译器通常将这两类算子分开优化，导致融合边界僵化、难以充分利用片上数据复用。作者还观察到，后续的内存密集型操作有时可以与计算密集型算子并行执行并被计算过程隐藏，但自动挖掘这一机会具有挑战性。
> **方法**: ComFuse 是一个自动化 GPU 编译系统，提出了一种新的算子融合策略，用于生成面向复杂图结构的高性能内核，尤其适用于计算密集型算子与依赖关系复杂的内存密集型 elementwise-reduction 子图的融合。它还支持 back-to-back GEMM（B2BGEMM）模式，并可将高层 tensor 子程序自动下沉为优化后的融合内核，以减少手工内核工程需求。
> **关键结果**: 实验结果表明，ComFuse 生成的融合内核在 post-norm 工作负载以及多种复杂计算场景下，性能优于 TorchInductor 生成的内核。与此同时，它支持更灵活的融合模式。
> **与本课题相关性**: 该工作直接关注现代 GPU 架构上的算子融合与编译优化，核心目标是提升复杂计算图中计算密集与内存密集部分的协同执行效率。它属于深度学习编译与高性能 GPU kernel 生成方向的代表性研究。
> **局限**: 摘要未给出 ComFuse 在不同模型、不同 GPU 平台或极端图结构下的具体性能边界，因此其适用范围与代价难以仅从摘要中完全判断。摘要也未说明编译开销、实现复杂度或潜在失败案例。

### Fovea: Physical-Implication-Aware Wafer-Scale DSE with Decision-Domain-Guided Cross-Fidelity Refinement
- **作者**: Jinxi Li, Huizheng Wang, Jinyi Deng, Yang Hu, Shouyi Yin
- **来源**: arXiv:cs.AR  · `2608.03285v1`
- **链接**: https://arxiv.org/abs/2608.03285v1
- **PDF**: https://arxiv.org/pdf/2608.03285v1
- **发布日期**: 2026-08-04

> **动机**: 传统预硅设计空间探索（DSE）通常采用“粗筛—精评”流程，但在晶圆级系统中，架构选择会同时影响reticle约束、晶圆切片、die面积、D2D能力、边界访问和布局等物理因素，使得设计空间不能简单视为笛卡尔积。与此同时，精细评估代价过高，且分析模型到参考结果的排序反转会让固定候选集不可靠。
> **方法**: Fovea提出一种面向工作负载的晶圆架构选择方法，先进行物理影响感知的设计空间建模，在保留跨维度权衡的同时做仅影响评估器的局部约简，形成可建模且可行的空间。随后通过“决策域引导的跨保真细化”，用成对域内校准估计分析与参考评估的不一致性，构造参考一致的性能区间并选择性触发指定参考评估。
> **关键结果**: 在10个可用参考验证的设计空间和7个LLM训练工作负载上，使用10%的成对校准，Fovea在70个评估配对中都恢复了穷尽指定参考评估下的最优解。其端到端平均加速比为4.13倍，最大加速比为7.80倍。
> **与本课题相关性**: 该工作直接面向晶圆级系统的设计空间探索，关注如何在复杂物理约束下高效、可靠地做架构选择。它结合物理约束建模与跨保真优化，适合用于大规模芯片/系统架构搜索场景。
> **局限**: 方法依赖于“域宽不一致性上界”成立，且其有效性通过采样式实现并在可穷尽参考验证的空间上评估。摘要中未说明该方法在更大、不可穷尽空间中的泛化情况，也未给出对上界假设失效时的表现。

### Unified Lookup-Table Inference with Signed-Digit K/V Caches for Ternary LLMs
- **作者**: Ziang Duan, Jiajun Wu, Zetian Chen, Hao Song, Yanwen Deng et al.
- **来源**: arXiv:cs.AR  · `2608.03229v1`
- **链接**: https://arxiv.org/abs/2608.03229v1
- **PDF**: https://arxiv.org/pdf/2608.03229v1
- **发布日期**: 2026-08-04

> **动机**: Ternary LLM 的权重投影已经很紧凑高效，但注意力模块的 K/V cache 仍然在线生成且通常依赖更高精度的独立引擎，造成执行机制不统一。仅压缩 cache 本身并不能消除这种不匹配，因此需要让注意力也能使用与三值投影一致的查表式推理机制。
> **方法**: 本文提出统一的查表推理方法，将运行时 K/V 状态存为围绕注意力归约结构组织的缩放多平面有符号数字，并让这些数字平面直接被由激活生成的查找表消耗。该设计还结合了在线 K/V 形成、对未完成值块的有界处理，以及用于线性层和注意力的共享多流数据通路，并通过约束指导搜索选择表示与执行策略。
> **关键结果**: 实验表明，该方法可在原生和后训练三值模型上工作，并在 cache 容量、模型质量和硬件效率之间取得可控权衡。结果验证了把 attention 的 K/V cache 也纳入统一查表框架的可行性。
> **与本课题相关性**: 这篇工作直接研究三值 LLM 的推理加速，核心是把 K/V cache 与 attention 计算一起纳入统一的低比特查表执行框架。它与“高效三值模型推理”和“缓存压缩/统一硬件执行”主题高度相关。
> **局限**: 摘要没有给出具体实验数值、与哪些基线相比以及在多大规模模型上的表现，因此无法从摘要判断提升幅度。方法还依赖约束指导搜索来选取表示和执行策略，说明部署时可能需要额外的设计与调参成本。

### Interpolation of Non-Linear Functions for LLMs using Partial Reconfiguration in FPGAs
- **作者**: Roger Morales-Monge, Nazareth Jimenez-Chacon, Jose Gabriel Villalobos-Alvarado, Luis G. Leon-Vega, Jorge Castro-Godinez
- **来源**: arXiv:cs.AR  · `2608.03033v1`
- **链接**: https://arxiv.org/abs/2608.03033v1
- **PDF**: https://arxiv.org/pdf/2608.03033v1
- **发布日期**: 2026-08-04

> **动机**: 指数和 sigmoid 等非线性函数对 AI 和 LLM 加速很关键，但在 FPGA 上高效实现它们的硬件成本仍然较高。作者希望在保持灵活性的同时，降低这类函数的实现开销。
> **方法**: 论文提出了一种基于部分重配置的分段线性插值（PWL）框架，将设计分为静态区域和可重配置区域。静态区域负责通信与控制，可重配置区域则按需加载不同的插值模块，并对指数和 sigmoid 在 FP16/FP32 下的均匀与非均匀分段策略进行评估。
> **关键结果**: 结果显示，非均匀分段在高曲率区域能提升精度，而均匀分段具有更低的硬件开销。系统层面上，相比同时包含两个算子的静态设计，可重配置实现最多减少 43% 的 LUT、50% 的 flip-flops、BRAM 和 DSP 单元，并且具有可预测的重配置延迟。
> **与本课题相关性**: 这项工作直接面向基于 FPGA 的 LLM 非线性函数加速，关注在精度、面积和延迟之间的权衡。它表明部分重配置是一种可行方式，可用于探索不同硬件实现方案的资源效率。
> **局限**: 摘要中的评估主要集中在指数和 sigmoid 两类函数，以及 FP16/FP32 两种数值格式，因此结论的适用范围仍然有限。虽然报告了面积节省和可预测延迟，但摘要没有给出更广泛工作负载或端到端 LLM 性能的结果。

### LACE: Large Language Model Aided Multi-Agent Framework for Agile RISC-V Instruction Extension
- **作者**: Pingqing Zheng, Jiayin Qin, Fuqi Zhang, Zishen Wan, Shang Wu et al.
- **来源**: arXiv:cs.AR  · `2608.02915v1`
- **链接**: https://arxiv.org/abs/2608.02915v1
- **PDF**: https://arxiv.org/pdf/2608.02915v1
- **发布日期**: 2026-08-03

> **动机**: RISC-V 生态中常用领域特定 ISA 扩展（ISAX）来加速新兴工作负载，但在不同内核上实现和验证这些扩展仍然缓慢且割裂。现有框架通常需要针对每个核心单独适配接口，而且当微架构或 ISAX 变化时，差分测试也容易失效。
> **方法**: LACE 是一个由大语言模型辅助的多智能体工作流，将自然语言形式的 ISAX 需求转为两级紧凑中间表示（操作级和 HDL 任务级）。它结合检索引导的局部 RTL 编辑，并通过编译器无关的 riscv-formal 检查流程闭环验证（前提是具备 RVFI 或相应插桩）。
> **关键结果**: 在四个嵌入式 RISC-V 核上的评估中，LACE 将 pass@1 生成准确率从接近 0 提升到 72.8%。同时，它改善了代码定位能力并减少了集成返工。
> **与本课题相关性**: 这篇论文直接讨论了使用大语言模型与多智能体框架来自动化 RISC-V 指令扩展的设计、实现与验证，属于 RISC-V ISA 扩展与自动化硬件开发的相关研究。它面向“敏捷”地生成和集成 ISAX，强调了从需求到 RTL 再到形式化验证的完整流程。
> **局限**: 该方法的形式化检查闭环依赖 RVFI 可用或能够进行相应插桩，因此对目标内核的可观测性有前提要求。摘要只说明在四个嵌入式 RISC-V 核和其评估设置中有效，泛化到更大范围的核心或更复杂扩展的效果尚未在摘要中给出。

### Celty: SpMspV GPU Kernel and SIMT Co-Design for Efficient Dual-Sparse LLM Inference
- **作者**: Ruokai Yin, Priyadarshini Panda
- **来源**: arXiv:cs.AR  · `2608.01536v1`
- **链接**: https://arxiv.org/abs/2608.01536v1
- **PDF**: https://arxiv.org/pdf/2608.01536v1
- **发布日期**: 2026-08-02

> **动机**: LLM 推理越来越依赖稀疏性来降低成本，但现有工作多只优化权重稀疏或激活稀疏中的一种，而且主要面向批量多用户推理。双稀疏将非结构化权重剪枝与运行时激活稀疏结合，适合单用户解码，但会形成现有 GPU kernel 处理不佳的 spMspV 工作负载。
> **方法**: 作者提出 Celty，一个面向 spMspV 的软硬件协同设计方案，包括稀疏格式、GPU kernel 和 SIMT 微架构。其 kernel 采用 RLC-CSC 格式以支持压缩权重列的向量化加载并减少不必要的内存访问，而 Sparse SIMT Core 则加入流水化 RLC 解码器和重用本地寄存器文件来实现无冲突累加。
> **关键结果**: Celty 的 GPU kernel 相比 cuBLAS 最多提升 2.8x，相比 Flash-LLM 最多提升 2.4x。结合 Sparse SIMT Core 后，在 70% 双稀疏条件下，相比 cuBLAS 的加速最高可达 5.3x。
> **与本课题相关性**: 这项工作直接面向大语言模型推理中的双稀疏计算与 GPU 加速问题，核心贡献是针对 spMspV 这一稀疏算子进行格式、内核和架构协同优化。它与稀疏推理、LLM 加速和 GPU/SIMT 设计主题高度相关。
> **局限**: 该方法主要针对单用户解码场景下的双稀疏 LLM 推理，适用范围不同于许多面向批量多用户推理的现有方法。摘要未给出其在不同模型、稀疏率或硬件平台上的更广泛验证结果。

### DeVIT: Low-Power Vision Transformer Acceleration Using Delta Computation
- **作者**: Reyhaneh Hosseinzadeh, Parham Zilouchian Moghaddam, Mehdi Modarressi
- **来源**: arXiv:cs.CV  · `2608.01343v1`

- **PDF**: https://arxiv.org/pdf/2608.01343v1

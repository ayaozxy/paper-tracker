### A Thread-Register Decoupled GPU Execution Model for Efficient Tensor Computation
- **作者**: Zihan Liu, Jingwen Leng, Yangjie Zhou, Yitong Ding, Guanlin Zhu et al.
- **来源**: arXiv:cs.AR  · `2608.19628v1`
- **链接**: https://arxiv.org/abs/2608.19628v1
- **PDF**: https://arxiv.org/pdf/2608.19628v1
- **发布日期**: 2026-08-20

> **动机**: 现代 GPU 虽然不断提升 Tensor Core 的总体吞吐，但在现代 AI 工作负载中，GEMM 与多种非 GEMM 操作交织时，如何高效编排完整的张量计算流水线仍然困难。作者认为主要瓶颈在于固定并行度和粗粒度调度。
> **方法**: 提出 FIBER，一种扩展 GPU SIMT 模型的新架构，其基本执行单元 fiber 与私有寄存器所有权解耦，仅携带最小控制状态，并通过共享视图访问 SM 寄存器。为实现这一点，论文扩展了 ISA、微架构和编译器，以支持共享寄存器寻址、无冲突的操作数传递和基于 fiber 的程序映射。
> **关键结果**: 在典型的混合精度 LLM 服务场景中，FIBER 在 Ampere 上实现了 2.25x 的端到端加速，在原始 FP16 计算下为 1.15x；在 Hopper 和 Blackwell 上分别达到 1.8x 和 2.09x。核函数级别的提升最高可达 2.49x。
> **与本课题相关性**: 这项工作直接面向 GPU 上的张量计算效率问题，尤其关注 Tensor Core 时代的执行模型与资源调度优化。它通过线程与寄存器解耦来提升张量计算的并行组织能力，属于高性能 GPU 计算与张量执行架构研究。
> **局限**: 摘要主要报告了混合精度 LLM 服务场景下的性能收益，未提供更广泛工作负载上的评估结果。也没有在摘要中说明实现复杂度、硬件开销或潜在兼容性限制。

### HYDRA: A Heterogeneous Chiplet DSE Framework for Serving Dynamic Hybrid LLM Workloads
- **作者**: Jiahao Lin, Alish Kanani, Sangwan Lee, Jaehyun Park, Umit Ogras
- **来源**: arXiv:cs.AR  · `2608.19395v1`
- **链接**: https://arxiv.org/abs/2608.19395v1
- **PDF**: https://arxiv.org/pdf/2608.19395v1
- **发布日期**: 2026-08-19

> **动机**: 混合 Transformer-Mamba 大语言模型虽然能提升长上下文效率，但其异构计算与通信模式使硬件加速和部署优化变得复杂。由于芯粒系统中的架构配置与运行时策略组合空间巨大，穷举探索代价过高，因此需要高效的设计空间探索框架。
> **方法**: HYDRA 是一个面向异构芯粒系统的设计空间探索框架，联合搜索芯粒组成、布局、芯粒间带宽分配、动态批处理和运行时调度。它结合了通信感知布局、动态批处理、弹性任务调度以及基于马尔可夫的快速性能估计器，以高效评估多租户运行时动态。
> **关键结果**: 实验结果显示，HYDRA 在所有工作负载上平均实现 1.55 倍吞吐量提升，并将首个 token 延迟降低 43.7%。与现有最先进基线相比，其吞吐量提升最高可达 2.3 倍。
> **与本课题相关性**: 该工作直接面向异构芯粒系统上的混合 LLM 服务，属于硬件架构、系统优化与运行时协同设计的研究。它展示了通过联合设计架构与调度策略，可以显著提升动态 LLM 工作负载的服务效率。
> **局限**: 摘要没有给出具体的芯粒规模、硬件实现细节或估计器误差等信息，因此难以判断方法的适用边界。文中结果主要基于与基线的对比，摘要未说明在更广泛真实部署条件下的鲁棒性。

### Coverage-Driven RTL Assertion Generation with Formal Exploration and Neuro-Symbolic Refinement
- **作者**: Zhiyuan Yan, Ziyue Zheng, Hongce Zhang
- **来源**: arXiv:cs.AR  · `2608.18482v1`
- **链接**: https://arxiv.org/abs/2608.18482v1
- **PDF**: https://arxiv.org/pdf/2608.18482v1
- **发布日期**: 2026-08-19

> **动机**: RTL 设计验证依赖高质量断言，但现有断言挖掘方法常因随机或有限轨迹而覆盖不到难以到达的行为，也缺少对未验证区域的反馈与持续改进机制。结果是即使生成了很多断言，关键设计行为仍可能未被覆盖。
> **方法**: 本文提出 NeuroAssertion，一个覆盖驱动的断言生成框架，结合形式化轨迹生成、SyGuS 语法引导合成以及类智能体的迭代 refinement 流程。它先把难以到达的控制流条件转为可达性目标，用模型检查生成多样化轨迹并挖掘初始断言，再基于验证反馈对未覆盖区域进行候选生成与修复合成。
> **关键结果**: 实验表明，该框架相比传统断言挖掘方法可生成约 2 倍更多的断言，并获得约 2 倍更高的 mutation coverage。作者还报告了其在覆盖驱动改进断言集方面的有效性。
> **与本课题相关性**: 这项工作直接面向硬件功能验证中的 RTL 断言自动生成问题，核心贡献是把覆盖、形式化探索和神经符号修复统一到一个框架中。它与“覆盖驱动的 RTL 断言生成”这一主题高度相关。
> **局限**: 摘要没有给出该方法在不同设计规模、复杂度或工程部署中的具体局限，也未说明其对 LLM 质量或形式化工具开销的敏感性。除此之外，摘要仅提供了总体结果，缺少更细粒度的误差分析与失败案例。

### Automated Estimation of MBIST Area and Test Time in Heterogeneous Memory IPs via Stacked Ensemble Framework
- **作者**: Chee Jin Teoh, Ab Al-Hadi Ab Rahman, Johnny Kee Hui Wong, Premkumar A/L Kesavan Prabagaran, Muhammad Nadzir Marsono et al.
- **来源**: arXiv:cs.AR  · `2608.19705v1`
- **链接**: https://arxiv.org/abs/2608.19705v1
- **PDF**: https://arxiv.org/pdf/2608.19705v1
- **发布日期**: 2026-08-20

> **动机**: 嵌入式存储器在现代 SoC 中占比很大，而 MBIST 会带来面积和测试时间开销，因此需要在设计早期快速、准确地估计这些成本。传统依赖 RTL 综合和测试向量生成的方法较慢且资源消耗高，不利于早期规划。
> **方法**: 作者提出一个监督学习框架，直接根据 RTL 级设计参数预测 MBIST 面积和测试时间，无需先进行完整综合。面积预测采用多项式扩展、对数变换与归一化后，使用由 XGBoost、LightGBM 和神经网络组成的堆叠集成模型，以梯度提升作为元学习器；测试时间预测则结合 XGBoost 与 LightGBM，并用 Ridge Regression 融合，超参数通过 100 次 Optuna 搜索调优。
> **关键结果**: 在面积预测上，模型在 ±10% 误差范围内达到 90.68% 的准确率；在测试时间预测上达到 96.80%。相较基线方法，面积和测试时间分别提升了 8.53% 和 48.80%。
> **与本课题相关性**: 这项工作直接面向异构内存 IP 的 MBIST 面积与测试时间估计问题，属于面向硬件设计早期成本预测的自动化方法。它展示了机器学习可用于替代部分昂贵的 RTL 综合与测试生成流程，从而支持更高效的设计决策。
> **局限**: 摘要中未明确说明模型在不同工艺、不同设计流或未见过的内存配置上的泛化能力，也未给出对误差来源的详细分析。数据集来自特定工具链生成，方法的适用范围可能受数据分布限制。

### Performance Verification of the AmpereOne CPU Core
- **作者**: Doa'a Al-Otoom, Nicholas Kelly, Aaron Lindsay, Agreen Ahmadi, Ananth Kumar et al.
- **来源**: arXiv:cs.AR  · `2608.19300v1`
- **链接**: https://arxiv.org/abs/2608.19300v1
- **PDF**: https://arxiv.org/pdf/2608.19300v1
- **发布日期**: 2026-08-19

> **动机**: 随着工艺制程缩放放缓，微架构创新已成为性能提升的主要来源，因此在硅前进行性能验证（PV）变得更加关键。本文旨在说明如何通过系统化的PV方法，在复杂CPU设计阶段尽早发现性能问题并降低流片后风险。
> **方法**: 作者提出并展示了一套用于四代 AmpereOne 定制CPU核的工业级PV方法，核心是将RTL设计与基于trace的性能模型进行周期级相关性验证。该方法结合了数据驱动的工作负载筛选、高频每日回归系统，以及统一的事件流分析框架，并采用先单元后整核的分层验证策略。
> **关键结果**: 论文通过分支预测单元和L2预取器两个案例展示了该方法的有效性，说明先对单个模块进行精细相关性分析，再扩展到全核验证，是可行且高效的。作者强调，这种迭代且有纪律的流程对于避免昂贵的流片后缺陷并确保性能目标达成至关重要。
> **与本课题相关性**: 这篇论文直接讨论了处理器性能验证方法，尤其是面向工业级CPU核的硅前性能验证流程。它对微处理器架构、RTL验证、性能建模和高性能计算芯片开发都具有直接相关性。
> **局限**: 摘要没有提供具体的定量性能提升、验证覆盖率或错误发现数量，因此难以评估方法的规模化效果。文中主要以方法论和案例展示为主，未在摘要中说明与其他PV方法的系统性对比。

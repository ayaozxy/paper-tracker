### Simthesizer: An Agent-Driven Simulation Framework for LLM Serving Systems
- **作者**: Wonung Kim, Hyunmin Choi, Minsu Kim, Jaehong Cho, Yeongwook Kim et al.
- **来源**: arXiv:cs.AR  · `2608.24650v1`
- **链接**: https://arxiv.org/abs/2608.24650v1
- **PDF**: https://arxiv.org/pdf/2608.24650v1
- **发布日期**: 2026-08-25

> **动机**: LLM serving 系统快速演进，诸如 agentic workflows 和 disaggregated serving 等新机制已经超出现有单体式模拟器的设计假设。由于真实部署成本高且往往不可行，系统级模拟需要一种能够更快跟进新特性的开发方式。
> **方法**: 论文提出 Borg，一个面向 agent 驱动的模拟器开发框架，通过可组合的模拟器基础设施将完整 serving 流程及其控制决策统一表示为动态图。随后由受约束的编码代理 Synthesizer 将自然语言特性需求映射到这一抽象上，并借助模拟器特定护栏与保真度验证持续演化同一个模拟器。
> **关键结果**: 在与 vLLM 真实系统对齐的扩展上，Borg 的平均吞吐量误差为 2.51%，而基于现有模拟器的扩展误差为 6.03%。在相同工作负载下，Borg 的仿真速度相较 LLMServingSim2.0 和 Vidur 分别最高快 284.96 倍和 23.19 倍。
> **与本课题相关性**: 该工作直接针对 LLM serving 系统的模拟与性能评估，关注如何更高效地支持不断出现的新型工作流和机制。它为 LLM serving simulator 提供了一种更易扩展、可由代理辅助开发的框架。
> **局限**: 摘要没有详细说明该方法在更广泛场景下的适用边界、失败案例或开发成本。也未提供关于不同工作负载和不同类型新机制的更细粒度限制分析。

### Thermal Tuning Overhead in Wafer-Scale Optical Interconnects for LLM MoE Training: A Cross-Layer Analysis and Ferroelectric-Based Mitigation
- **作者**: Seongwon Yoon, Pin-Jun Chen, Shimeng Yu
- **来源**: arXiv:cs.AR  · `2608.24637v1`
- **链接**: https://arxiv.org/abs/2608.24637v1
- **PDF**: https://arxiv.org/pdf/2608.24637v1
- **发布日期**: 2026-08-25

> **动机**: LLM，尤其是MoE架构的训练通信开销很大，使互连带宽需求迅速上升。基于DWDM的晶圆级光互连虽有潜力，但传统MRR依赖热光调谐，容易受到工作负载引发的温度波动影响。
> **方法**: 作者进行了跨层分析，结合MoE工作负载画像、分组级网络仿真和瞬态热分析。具体包括在ht-sim中实现晶圆级拓扑，并用Ansys建立3D集成GPU/EIC/PIC堆栈的热模型，再将热模型得到的调谐停顿注入网络仿真。
> **关键结果**: 结果显示，瞬态温度变化会超过传统热光控制环的跟踪能力，导致通信阶段反复出现调谐停顿。引入铁电电光调谐机制、消除持续热调谐需求后，在四层代理仿真中，相比热光方案，Mixtral 8x7B、Qwen-MoE 14.3B 和 LLaMA-MoE 6.7B 分别获得 2.7x、3.8x 和 3.3x 加速。
> **与本课题相关性**: 该工作直接讨论了面向LLM MoE训练的晶圆级光互连中的热调谐开销问题，并提出了铁电调谐的缓解方案。它说明了光互连性能不仅取决于带宽，也取决于调谐延迟这一关键系统瓶颈。
> **局限**: 文中结果主要来自仿真与热模型驱动的代理实验，而不是对真实硬件系统的实测。结论也集中在特定的MoE模型、晶圆级拓扑和所建模的3D堆栈上，泛化到其他平台仍需进一步验证。

### Elastic KV Cache for LLM Serving:A Working Reclamation Mechanism, and Why Chunked Prefill Already Closes the Gap
- **作者**: Sathishkumar Sivashanmugam
- **来源**: arXiv:cs.AR  · `2608.23658v1`
- **链接**: https://arxiv.org/abs/2608.23658v1
- **PDF**: https://arxiv.org/pdf/2608.23658v1
- **发布日期**: 2026-08-24

> **动机**: LLM 服务引擎通常在启动时一次性为最坏情况的 prefill 激活预留 KV cache 内存，但在以 decode 为主的阶段这部分内存会闲置，因此作者想研究这块“预留区”是否可以被回收再利用。
> **方法**: 作者提出一种纯用户态的 elastic KV cache 机制，利用 CUDA 虚拟内存把两块物理句柄映射到同一段连续虚拟地址上，在 decode 时借出预留内存给 KV pool、在 prefill 前归还，并由调度器基于下一批次的视角进行切换。
> **关键结果**: 实验表明该机制在技术上可行、不会触发 OOM，也能兼容 CUDA graphs 和 prefix caching，但收益有限：在其控制实验中，8192 与 32768 token 的 chunk size 之间 TTFT 中位数仅相差约 1%。作者还发现，直接降低 max_num_batched_tokens 几乎能以相近延迟回收更多 KV 内存。
> **与本课题相关性**: 这篇论文直接讨论了 LLM serving 中 KV cache 的弹性管理与内存回收问题，属于大模型推理服务优化的相关工作。
> **局限**: 该工作得出的结论是负面的：只有当较小的 prefill chunk size 会显著拖慢 prefill 时，回收预留区才可能有明显收益。与此同时，tensor parallelism 会稀释可回收比例，从 TP1 的 16% 降到 TP4 的 2.7%。

### Spicing up Genetic Netlist Generation with LLMs
- **作者**: Stefan Uhlich, Yağız Gençer, Andrea Bonetti, Arun Venkitaraman, Chia-Yu Hsieh et al.
- **来源**: arXiv:cs.NE  · `2608.23317v1`
- **链接**: https://arxiv.org/abs/2608.23317v1
- **PDF**: https://arxiv.org/pdf/2608.23317v1
- **发布日期**: 2026-08-24

> **动机**: 模拟电路拓扑综合很困难，因为有用设计在组合搜索空间中极其稀少，而且微小的结构变化会导致行为出现强非线性变化。传统进化算法虽然适合在黑盒评估下优化离散电路拓扑，但往往需要大量 SPICE 仿真，并且容易过早收敛。
> **方法**: 作者提出 LLM-SPICEMixer，一个将遗传 netlist 生成与 IGEL（基于 LLM 的启发式提议算子）结合的混合框架。搜索过程中，IGEL 会用高性能精英电路提示 LLM 生成新的 SPICE netlist，再通过 SPICE 评估并按与常规遗传算子相同的奖励机制进行选择。
> **关键结果**: 在 Iris 分类的晶体管级电路综合基准上，与不使用 LLM 引导的遗传框架相比，LLM-SPICEMixer 的训练集最终中位奖励提升了 8.4%，验证集选择的测试奖励中位数提升了 8.8%。最佳验证集选择电路在名义 tt corner 下达到 93.3% 的测试准确率，在 17 个工艺、电压和温度 corner 上平均测试准确率为 85.9%。
> **与本课题相关性**: 这篇论文直接讨论了用 LLM 辅助生成和优化电子电路 netlist，属于 LLM 参与电路/硬件设计自动化的典型工作。它展示了 LLM 可以作为结构化提案器，与仿真驱动的搜索结合来提升设计搜索效率。
> **局限**: 摘要中只报告了一个较具体的基准任务（Iris 分类的晶体管级电路），因此结果的泛化能力尚不能从摘要中确认。该方法仍然依赖 SPICE 仿真作为最终评估来源，因此整体搜索效率可能仍受仿真成本限制。

### Execution-Anchored Hallucination Calibration Reranking for Verilog Code Generation
- **作者**: Guang Yang, Xing Hu, Xiang Chen, Terry Yue Zhuo, Xin Xia
- **来源**: arXiv:cs.SE  · `2608.22938v1`
- **链接**: https://arxiv.org/abs/2608.22938v1
- **PDF**: https://arxiv.org/pdf/2608.22938v1
- **发布日期**: 2026-08-24

> **动机**: Verilog 等低资源硬件描述语言的代码生成仍然困难，尤其是在多候选采样后如何自动选择最优候选这一问题上，现有方法效果不稳定。作者通过系统研究发现，基于执行结果的 reranking 受测试平台质量限制，而 LLM-as-a-Judge 又容易出现推理幻觉。
> **方法**: 提出 EAHC（Execution-Anchored Hallucination Calibration）重排序框架，将执行信号与推理信号独立获取，并在决策阶段融合，而不是让推理器直接观察执行结果。该框架包含两个通道：EAHC-R 作为 4B 推理判别器，EAHC-T 作为结合 RAG 的测试平台生成器，用于执行验证。
> **关键结果**: 作者在九个模型和两个基准上做了系统实证研究，指出执行式 reranking 的可迁移性较差、LLM 评判存在对执行等价代码判断不一致的问题。基于这些发现，他们设计了 EAHC 来缓解执行信号覆盖有限与推理幻觉之间的矛盾。
> **与本课题相关性**: 这项工作直接面向 Verilog 代码生成中的候选重排序问题，属于用 LLM 改进硬件代码生成质量的研究。它强调了结合执行验证与语义判断的重要性，对提升低资源 HDL 场景下的自动代码选择很有参考价值。
> **局限**: 从摘要看，现有方法的问题主要来自低质量测试平台和推理幻觉，因此 EAHC 的效果仍可能受测试覆盖与生成器质量影响。摘要未给出具体性能数值或在更广泛 HDL/任务上的泛化结果。

### NOVA: Technology-Architecture Co-Design of Near-Memory Processing for Attention-SSM-MoE Hybrid LLM Inference
- **作者**: In-Jun Jung, Jaeha Min, Joo-Young Kim
- **来源**: arXiv:cs.AR  · `2608.22613v1`
- **链接**: https://arxiv.org/abs/2608.22613v1
- **PDF**: https://arxiv.org/pdf/2608.22613v1
- **发布日期**: 2026-08-23

> **动机**: 混合LLM将GQA、SSM和MoE层交错使用，但现有近内存处理（NMP）架构同时面临“技术墙”和“架构墙”：DRAM单元继续缩放困难，而传统NMP又难以覆盖这类模型中跨度很大的计算强度需求。作者因此希望通过技术与架构协同设计来支撑下一代混合LLM推理。
> **方法**: NOVA在技术上采用4F²垂直通道晶体管（VCT）DRAM单元与peri-over-cell（POC）结构，以在相同面积下实现约2倍存储密度；在架构上，将POC的peri-die用于部署处理单元，构成两层NMP：Tier-1面向低到中等Op/B，Tier-2面向中到高Op/B，并支持跨层并行执行。
> **关键结果**: 在Nemotron3-Nano、Nemotron3-Super、Falcon-H1R和Qwen3等混合与MoE LLM上的评估显示，NOVA相较GPU基线平均可提升4.5倍吞吐量、降低69.8%端到端延迟，并提高5倍能效。与此同时，其面积开销仅3.9%，且不损失存储容量。
> **与本课题相关性**: 这篇工作直接针对“注意力-SSM-MoE混合LLM推理中的近内存处理”主题，提出了兼顾存储密度与异构计算适配的系统方案。它把器件技术和NMP架构联合设计起来，正好对应该领域中容量扩展与高效推理并重的核心问题。
> **局限**: 摘要没有详细说明NOVA在更广泛硬件平台、真实部署环境或制造成本方面的限制，因此这些内容无法从摘要中判断。文中主要报告的是性能、能效和面积指标，未提供更细粒度的失败案例或适用边界。

### Architecting the Next Generation of Asynchronous, Distributed GPUs for the AI Era
- **作者**: Junrui Pan, Weili An, Cesar Avalos Baddouh, Christin David Bose, Ni Kang et al.
- **来源**: arXiv:cs.AR  · `2608.22602v1`
- **链接**: https://arxiv.org/abs/2608.22602v1
- **PDF**: https://arxiv.org/pdf/2608.22602v1
- **发布日期**: 2026-08-23

> **动机**: 机器学习工作负载的快速演进正在重塑GPU硬件，使其走向多芯片模块（MCM）、异步执行原语和持续多阶段内核等新特征。现有周期级模拟基础设施却未能原生刻画现代GPU的物理非均匀性，也难以支撑大规模AI工作负载的建模。
> **方法**: 作者提出了一个周期级模拟框架，用于精确模拟现代GPU世代，包括Ampere、Hopper和Blackwell。该框架通过与真实硅片进行严格验证，并在H100上达到99%的Pearson相关系数和13.4%的平均绝对周期误差。
> **关键结果**: 该模拟器在H100上的验证结果表明其与硬件行为高度一致，能够用于可信的架构研究。基于此工具，作者进一步分析了芯粒拓扑扩展、SRAM容量与带宽提升以及跨GPU预取等新兴设计方向。
> **与本课题相关性**: 这篇论文直接关注AI时代下一代异步、分布式GPU的架构建模与评估，核心是支持对现代GPU设计演进的周期级研究。它与“面向AI时代的异步、分布式GPU架构设计”主题高度相关。
> **局限**: 摘要主要强调了模拟框架的验证结果和案例研究，但没有给出更广泛的工作负载覆盖范围或对所有GPU场景的适用边界。它也没有在摘要中详细说明具体实现开销、仿真性能或可能的失配情况。

### Precision-Aware Variable Bit Processing Elements for Hardware-Efficient Systolic Array Designs
- **作者**: Dantu Nandini Devi, Madhav Rao
- **来源**: arXiv:cs.AR  · `2608.22378v1`
- **链接**: https://arxiv.org/abs/2608.22378v1
- **PDF**: https://arxiv.org/pdf/2608.22378v1
- **发布日期**: 2026-08-23

> **动机**: 研究旨在为深度学习中的矩阵运算构建更高效的硬件加速器，尤其是在可容忍一定近似误差的场景下，降低浮点乘法器和脉动阵列的面积、功耗与延迟。作者关注FP32、TF32和BF16等浮点格式下的精度与效率权衡。
> **方法**: 作者在权重驻留型脉动阵列的浮点乘法器中引入部分积矩阵列截断，并结合正负压缩器进行近似设计，以优化计算开销与输出精度之间的平衡。与此同时，使用NSGA-II对设计空间进行搜索，生成不同的近似浮点乘法器和处理单元方案。
> **关键结果**: 实验表明，这些近似处理单元在MNIST、F-MNIST和CIFAR-10上能保持与精确实现相近的CNN准确率。对于CIFAR-10，表现较好的前10个近似SA设计相较精确实现可带来约66%–92%的面积节省、60%–93%的功耗收益以及21%–54%的延迟改善，TF32和BF16设计也取得了类似优势。
> **与本课题相关性**: 该工作直接面向“精度感知的可变比特处理元件”和“硬件高效脉动阵列设计”，展示了通过浮点乘法器近似化提升AI加速器效率的可行路径。它为在误差容忍应用中优化硬件资源提供了具体方法与实证支持。
> **局限**: 摘要主要报告了整体面积、功耗、延迟和分类准确率的结果，但没有给出更细粒度的误差分析或设计参数细节。文中结论也主要基于特定数据集和CNN任务，泛化到其他模型与工作负载的情况未在摘要中说明。
